# GeoVerify – Map Data Quality Audit

## Project Overview
GeoVerify is a self-created demonstration project designed to showcase basic mapping operations and map data quality verification skills.

## Tools Used
- Google My Maps
- Google Sheets

## Project Objectives
- Identify and organize map locations.
- Check location names and addresses.
- Verify location categories.
- Identify possible duplicate records.
- Maintain verification status and recommended actions.

## Project Components

### 1. Location Data
Organizes location records, verification status, issues and recommended actions.

### 2. Address Verification
Maintains address-checking records using Google Maps as a reference.

### 3. Category Verification
Compares actual and listed categories for selected locations.

### 4. Project Summary
Provides an overview of the project, tools and activities.

This is an independent learning and demonstration project. Some spreadsheet records are fictional training examples. It is not an official Wipro project or production mapping system.
